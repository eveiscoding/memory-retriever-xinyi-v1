Opt-in output consumer for preserved branch13 Search. Resolve Top20 provenance under a read-only connection, release it, then make_candidates(query, tokenizer), score_candidates(query, scorer), selected_output(budget, tokenizer). API uses exact original spans; 384-token windows, overlap64, actual query+role+special pair<=512; short replies and assistant head spans add preceding context up to96 reference tokens when source is already in parent universe. Global source-score order only affects evidence output, not Search IDs/order. Overlap union only within same original message, no bridging gaps or cross-source dedup. Full unified rendered metadata and separators count toward budget. Missing provenance, tenant mismatch, invalid scores and query too long raise; no silent fallback or generated text. This module is not wired to HTTP Search/Answer and does not change defaults. Sources: LlamaIndex SentenceWindow and LangChain ParentDocumentRetriever concepts; implementation adapted to existing source IDs without framework dependency. Use driver prelock/run for six reused public cases; compare whole-view prefix at4096/8192.
